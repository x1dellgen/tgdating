## [0.9.0] — 2026-07-13

### Добавлено

**Этап 9 — Анонимный чат с радаром и конверсией:**
* Полноценный `AnonymousChatScreen.tsx` с тремя состояниями: `setup`, `searching`, `chatting`
* Экран настроек (`setup`): выбор пола собеседника (Парень/Девушка/Все) и кнопка «Начать поиск»
* Экран радара (`searching`): пульсирующая CSS-анимация радара с `animate-ping`, авто-подключение через 3–4 секунды
* Жёсткий возрастной ценз при поиске: подростки (14–17) ↔ подростки, взрослые (18+) ↔ взрослые
* Фильтрация собеседников по выбранному полу из `mockProfiles.ts`
* Анонимный диалог (`chatting`): шапка «Анонимный собеседник» с полом/возрастом, бабблы сообщений, автоскролл
* Эмуляция ответов собеседника через 1.5–2 секунды (уникальные фразы для анонимного чата)
* Кнопка «Следующий собеседник» ➡️ — разрыв чата и мгновенный перезапуск радара
* Кнопка «Завершить диалог» ✕ — возврат на экран настроек
* Кнопка «Поделиться анкетой» (шаринг профиля) с проверкой наличия анкеты в `RegistrationContext`
* Модальное окно «Нет анкеты» с кнопкой перехода на Onboarding для создания профиля
* Системное сообщение `[Вы поделились своей анкетой знакомств]` и ответная карточка профиля собеседника
* Мини-карточка профиля с фото, именем, городом, био и кнопкой «Перейти в дейтинг»
* Интеграция с Welcome Screen: кнопка «Анонимный чат» ведёт на `AnonymousChatScreen`

### Изменено

* `AnonymousChatScreen.tsx`: полностью переписан (была заглушка «В разработке»)

## [0.8.0] — 2026-07-13

### Добавлено

**Этап 8 — Интерактивный каталог анкет:**
* Полностью переработан `CatalogTab.tsx` — убрана заглушка «В разработке»
* Поисковая строка: динамический поиск по имени или городу (без учёта регистра), кнопка очистки
* Панели фильтров: горизонтальный скролл тегов для целей знакомства и интересов
* Адаптивная сетка анкет 2×N с мини-карточками (фото, имя, возраст, город, цель)
* Модальное окно с детальной анкетой: полная информация, фото, интересы, био
* Действия в модальном окне: ❤️ Лайк (30% шанс мэтча), ⭐ Суперлайк (30% шанс мэтча + console.log), 🙈 Скрыть, 🚩 Пожаловаться
* Жёсткий возрастной ценз (14–17 / 18+) как в свайпах
* Составной фильтр: возрастной ценз → текстовый поиск → цели → интересы → исключение скрытых
* Анимация `slide-up` для модального окна (добавлена в Tailwind config)
* Утилита `scrollbar-hide` для скрытия полос прокрутки в горизонтальных фильтрах

### Изменено

* `tailwind.config.js`: добавлены keyframes `slide-up` и animation `slide-up`
* `index.css`: добавлен класс `.scrollbar-hide`

## [0.7.0] — 2026-07-12

### Добавлено

**Этап 7 — Lifecycle & Profile:**
* Локальный стейт `incomingProfiles` во вкладке Лайков (`LikesTab.tsx`) — карточки динамически удаляются при взаимодействии
* Кнопка «Пропустить» (✕) мгновенно удаляет анкету из стейта
* Кнопка «Взаимно» (❤️) запускает Match-оверлей и также удаляет анкету из стейта
* Режим редактирования профиля (`ProfileTab.tsx`) с флагом `isEditing`
* Режим просмотра: красивая карточка пользователя с кнопкой «Редактировать профиль»
* Режим редактирования: форма с полями (Имя, Город, О себе), 3 раздельных инпута даты рождения с автопереключением фокуса и поддержкой Backspace
* Интерактивные кликабельные теги для интересов и целей в редакторе
* Кнопка «Сохранить» с валидацией возраста (не младше 14 лет), сохранение в глобальный `RegistrationContext`
* Кнопка «Отмена» — сбрасывает локальные изменения, не трогает глобальный контекст
* Кнопка «Заполнить анкету с нуля» (красная) — очищает `RegistrationContext` и сбрасывает роутинг на Welcome Screen

### Изменено

* `LikesTab.tsx`: `displayProfiles` заменён с `useMemo` на `useState` для динамического управления списком
* `ProfileTab.tsx`: полная переработка с добавлением edit mode, локального `draft` стейта и трёх кнопок управления

## [0.3.0] — 2026-07-11

### Добавлено

**Этап 3 — Onboarding Process:**
* `OnboardingScreen` с пошаговым процессом регистрации из 6 шагов
* `StepBio` — ввод имени, даты рождения, города и описания
* `StepInterests` — выбор интересов из предустановленного списка (кликабельные теги)
* `StepGoals` — выбор целей отношений (кликабельные карточки)
* `StepPhotos` — загрузка фото (заглушка)
* `StepSearch` — настройка параметров поиска (пол, возрастной диапазон, город)
* `StepFinal` — финальный экран с подтверждением и переходом в Dating Shell
* `RegistrationContext` — глобальное состояние формы регистрации
* `calculateAge()` — утилита расчёта возраста по дате рождения
* `DEFAULT_REGISTRATION_FORM` — значения по умолчанию для формы
