# PROJECT VISION — Философия и цели продукта

## Миссия

Создать безопасную, минималистичную и удобную платформу для знакомств и анонимного общения
внутри экосистемы Telegram, которая уважает приватность пользователя и не навязывает лишних
механик.

## Ключевые принципы

1. **Приватность прежде всего.** Никакого сбора данных, которые не нужны для базовой
   функциональности. Анонимный чат должен оставаться анонимным.
2. **Минимализм.** Интерфейс не должен конкурировать с контентом. Пользователь приходит
   общаться, а не изучать интерфейс.
3. **Нативность Telegram.** Приложение выглядит и ощущается как часть Telegram:
   нативные цвета, темы, жесты, анимации.
4. **Инклюзивность.** Интерфейс доступен для людей с любым уровнем технической подготовки.

## Целевая аудитория

Пользователи Telegram, которые ценят:
* Удобство и скорость
* Анонимность и безопасность
* Отсутствие навязчивой рекламы и микротранзакций

## Ключевые разделы продукта

### 1. Дейтинг (Знакомства)

Пользователь просматривает профили и выражает симпатию. При взаимной симпатии открывается чат.

### 2. Анонимный чат

Пользователь попадает в случайную пару с другим участником платформы. Без имён,
без фото, без привязки к профилю. Чистый разговор.

### 3. Профиль (в будущем)

Минимальный профиль: имя, возраст, несколько фото, краткое био.
Без обязательных полей, без верификаций через соцсети.

## Что мы НЕ делаем

* ❌ Сложные алгоритмы рекомендаций на основе ИИ
* ❌ Рейтинги, «элитные» статусы, Premium-подписки
* ❌ Интеграцию с другими соцсетями
* ❌ Сбор телеметрии и поведенческий таргетинг
